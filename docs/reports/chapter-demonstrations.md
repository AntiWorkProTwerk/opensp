# Chapter demonstrations

The owner found the guide pages too similar. This extension gives each
chapter a different interactive explanation while preserving the published
account, evidence limits and approved monochrome design.

| Guide | Reader experiment |
| --- | --- |
| First change | Compare a fictional title record's length, terminator and surrounding bytes. |
| Pad information | Follow the direct-test and current-screen drawing routes. |
| First animation | Advance, hold, wrap and recreate widget-owned phase. |
| Verified capture | Distinguish length/checksum checks from provenance. |
| Original boot | Compare the recorded SHIFT counter deltas. |
| Mapping controls | Collapse eight aliases into one accepted button event. |
| Named inputs | Separate raw samples, published events and visible pixels. |
| USB updates | Distinguish RAM verification, stored content and running identity. |
| Keeping the updater | Inspect which package contains the writer after replacement. |
| Partial update | Compare shared and per-job time allowances. |
| RAM loader | Try competing owners of one buffer. |
| Finding audio | Compare neighboring words with the same position in successive frames. |
| Audio stream | Place an interrupt between timer reads and compare their order. |
| Original SDK | Inspect bounded signed-sample conversion and output bytes. |
| Bootloader boundaries | Separate a complete journal record from a confirmed candidate. |
| Pitch correction | Choose an allowed target note from an invented frequency estimate. |
| Synth design | Edit, store, initialize or cancel a fictional patch while retaining a take. |

These are teaching models. They accept no firmware, connect to no device and
produce no audio. Captured or owner-reported facts retain their original scope.
R3's preserved renderer replay stays inline; the other former milestone
sequences remain available in disclosures.

## Shared source

The model registry is [src/lib/demos](../../src/lib/demos/). Seventeen native
`Demo: <slug>` mains supply the actual SVG geometry through
[demo-components.json](../../design/penpot/demo-components.json). Thirty-four
Desktop/Mobile figure mains reuse those diagrams and Animation timeline.
[ChapterDemo](../../src/components/guides/ChapterDemo.astro) implements semantic
controls; its browser runtime loads one model group per page.

Native snapshots are explicit exports, not automatic synchronization. Scaled
text boxes and theme overrides retain component links. The authoring contract
records the export and verification steps.

components page. No other browser window was restarted.
