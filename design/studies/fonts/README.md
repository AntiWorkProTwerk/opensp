# Homepage fonts

Self-hosted Latin subsets, downloaded September 28, 2026 from Google Fonts:

- [Arimo](https://fonts.google.com/specimen/Arimo), variable upright 400–700:
  `https://fonts.gstatic.com/s/arimo/v36/P5sMzZCDf9_T_10ZxCE.woff2`
- [Cousine](https://fonts.google.com/specimen/Cousine), upright 400:
  `https://fonts.gstatic.com/s/cousine/v31/d6lIkaiiRdih4SpP_SQvzA.woff2`

The adjacent OFL files are from the Google Fonts repository. The homepage uses
these families to match its Penpot typography assets. `font-display: swap` keeps
text visible while loading; Arial and Courier New are fallbacks. Other scripts
use fallback fonts until the relevant licensed subsets are added.
