# First guide previews

These PNGs are direct Penpot exports of the four **First guide** boards, not
browser screenshots or AI-generated images. Desktop and mobile each have light
and dark layouts. Source IDs and geometry are in
[`first-guide-layouts.json`](../../penpot/first-guide-layouts.json); linked main
definitions are in [`guide-components.json`](../../penpot/guide-components.json).

Refresh the snapshots with `npm run design:pull-guide`, then run
`node tools/export-guide-previews.mjs` with the OpenSP editor connected. These
files are review evidence only and are not copied to the public website.
Native posters show static interaction states; the browser runs the animations.
